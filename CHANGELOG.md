# Changelog

All notable changes to AgentTrail are tracked here. Release notes live in `docs/RELEASE_NOTES_v*.md`; this file keeps the public timeline compact.

## Unreleased

- Added Epic AB community and growth foundation: launch response workflow, recipe marketplace curation, good-first issue backlog, governance, release process, showcase gallery, comparison benchmarks, and plugin SDK examples.

## v0.7.0

- Added documentation foundation: searchable static docs site, generated API reference, getting-started guide, backend setup, architecture, troubleshooting expansion, and video walkthrough plans.
- Added quality engineering foundation: coverage gate, fuzz tests, UI E2E in CI, performance regression checks, matrix CI, and eval scoreboard.

## v0.6.0

- Added supply-chain and distribution foundation: release checksums, SBOM, reproducibility checks, signing docs, npm publish docs, Docker workflows, and Homebrew formula updates.

## v0.5.0

- Added team and enterprise foundation: local users, RBAC, shared receipts, audit export, sync hooks, and SSO hook scaffolding.

## v0.4.0

- Added runtime and model distribution foundation: hardware policy, loading policy, registry workflows, bundled runtime seam, CLI parity, and desktop distribution scaffolding.

## v0.3.x

- Added trust and agent depth: semantic search, replayable sessions, MCP readiness, structured output, planner approvals, guardrails, reflection, memory, attachments, image/audio/document ingestion, and reports.

## v0.2.0

- Added early top-one-percent surfaces: README star engine, launch plan, recipe packs, static demo, trust score, security scan, and shareable reports.
