# Code Of Conduct

AgentTrail is a local-first AI agent project. The community should be practical, respectful, and safety-minded.

## Expected Behavior

- Be respectful when discussing ideas, code, security concerns, and design tradeoffs.
- Keep feedback actionable and focused on the project.
- Assume good intent, but stay precise when a bug or risk matters.
- Respect privacy. Do not ask contributors to share private files, secrets, logs, or credentials.
- Disclose security issues responsibly through the security policy instead of public exploit posts.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Publishing another person's private information.
- Spam, repeated off-topic promotion, or intentionally disruptive comments.
- Encouraging unsafe use of local agents, exfiltration, credential theft, or bypassing user approvals.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code. Repeated or severe violations may result in a block from the repository.

If you see a problem, open an issue or contact the repository owner with links, context, and the behavior that needs review.
