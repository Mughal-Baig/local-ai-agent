# Positioning Notes

GitHub has many local AI chat and Ollama UI projects. The largest projects win on platform breadth, integrations, document chat, and polished screenshots.

AgentTrail should avoid competing as a giant platform. Its sharper niche is:

- tiny local agent starter kit
- local workspace search before answers
- diff previews before writes
- visible tool receipts
- plain JSON agent recipes
- permission toggles and saved receipts
- workspace safety by default
- no npm dependency install
- readable implementation

## GitHub Growth Checklist

- Use a direct repository description.
- Add topics such as `ollama`, `local-ai`, `ai-agent`, `self-hosted`, and `privacy`.
- Keep the README screenshot current.
- Keep CI green.
- Show exactly what makes the app different above the fold.
- Lead with search, diff previews, and receipts as the unique trust loop.
- Turn common feature ideas into small, labeled issues.
- Encourage recipe contributions because they are small and easy to review.
