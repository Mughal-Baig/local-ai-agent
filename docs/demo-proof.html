Trust Score 100 proof loop

Search, preview, apply, receipt, report.

This page proves AgentTrail's core promise with deterministic demo data. The same files generate the README GIF, the receipt, and the shareable report, so launches can block when the proof gets stale.

npm run demo:proofregenerate
npm run demo:healthverify
