## What Changed From v0.4

- Semantic-lite is now a real persisted vector index path. If Ollama embeddings are available, AgentTrail stores model embeddings; otherwise it falls back to deterministic local vectors.
- Receipts now have replayable JSON session siblings, not just Markdown evidence.
- The MCP approval manifest now has a runnable stdio MCP server.
- Eval and benchmark surfaces now produce history the UI can show over time.
- Project memory now has citations and revision history, so users can inspect why memory influenced a run.

## Still Honest

AgentTrail is not yet a signed native desktop app, not yet published to npm/Homebrew/DockerHub, and not yet backed by a hosted community marketplace. The repo now has the implementation assets and docs needed to make those launches credible.
