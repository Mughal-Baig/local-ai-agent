# Community Growth Loop

AgentTrail should earn stars by making the value obvious in the first minute and making contribution paths small.

## Star Drivers

- Keep the GIF above the README fold.
- Keep the 60-second quick start tested.
- Make every release note show one concrete visual or trust improvement.
- Add recipe packs for specific roles instead of generic prompt lists.
- Keep issues small enough for first-time contributors.

## Good First Issue Backlog

- Add a student recipe pack.
- Add a writer recipe pack.
- Add a researcher recipe pack.
- Add a benchmark fixture for one popular local coding model.
- Improve the static demo copy for non-developers.
- Add screenshots for Windows and Linux launchers.
- Add an example MCP client configuration.

## Launch Checklist

- Post the GIF and quick-start command.
- Submit to local-first, Ollama, and open-source AI communities.
- Open five good first issues before launch.
- Ask early users for one recipe pack each.
- Tag releases with short notes and a screenshot or GIF.
